# results/pre_si

Snapshot of the reported numbers before the SI verification (commit aef9a3f). It holds the
number macros (`autogen_numbers_pre_si.tex`, `numbers.md`) and the hypothesis outcomes
(`hypotheses.json`) that `experiments/make_changes_si.py` compares with the current results to
build the old/new table in CHANGES_SI.md. The full pre-SI result files are in the git history at
commit aef9a3f; after the rerun they equal `results/full/` except for runtimes and
`rep_markov.json` (see CHANGES_SI.md).
